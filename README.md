# Social-sector-wwbsite-23

Static website (HTML, CSS, JS) on branch `v1`.

## Live preview (GitHub Pages)

After the deploy workflow runs, open:

**https://itsakshaysb.github.io/Social-sector-wwbsite-23/**

### One-time setup (repo owner)

1. Open **Settings → Pages** on GitHub.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. If the repository is **private**, you need a paid GitHub plan (Pro/Team/Enterprise) to use Pages. Then set **Pages visibility** to **Public** so anyone can open the link without repo access.

Pushes to `v1` automatically redeploy the site.
